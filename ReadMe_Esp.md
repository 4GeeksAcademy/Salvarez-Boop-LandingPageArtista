# README - Landing Page de Salvarez

## Resumen
Proyecto de landing page de una sola pagina para el artista escenico Salvarez.

El sitio incluye:
- Navegacion principal con anclas.
- Hero de bienvenida.
- Seccion Sobre mi.
- Seccion Trayectoria con 3 hitos.
- Seccion Proximas presentaciones con 2 fechas.
- Seccion de contacto.
- Pie de pagina.

## Estado actual (actualizado 2026-07-25)
- Estructura HTML5 semantica y accesible.
- CSS mobile-first con metodologia BEM y enfoque DRY.
- Diseno responsivo con Flexbox y Grid.
- Metadatos SEO completos en head.
- Open Graph y Twitter Cards.
- JSON-LD Schema.org (Person + WebSite).
- Uso de recursos en la carpeta Image.

## Archivos principales
- index.html
- styles.css
- prompts.md
- promtps.md

## Notas
- prompts.md contiene la version actual del prompt maestro.
- promtps.md se mantiene por compatibilidad con el nombre historico del repositorio.
- No se utiliza JavaScript ni frameworks externos.
