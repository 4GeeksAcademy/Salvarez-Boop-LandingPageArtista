🧩 Descripción General del Prompt Maestro
Este Prompt Maestro está diseñado para transformar cualquier modelo de IA en un generador profesional de código HTML + CSS, cumpliendo estándares modernos de accesibilidad, semántica, SEO y buenas prácticas de desarrollo.
Su estructura modular permite que la IA procese cada bloque como una instrucción independiente, garantizando resultados consistentes, limpios y accesibles.

El objetivo principal es producir solo código, sin explicaciones, utilizando Markdown con bloques de código, asegurando que la salida sea clara, exportable y lista para uso inmediato.
